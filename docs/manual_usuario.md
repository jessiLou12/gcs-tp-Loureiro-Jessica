# Manual de Usuario

## Gestor de Clientes

El sistema permite registrar nuevos clientes.

### Instrucciones
1. Abrir el archivo index.html en un navegador.
2. Ingresar el nombre del cliente.
3. Ingresar el correo electrónico.
4. Ingresar el teléfono.
5. Presionar el botón Registrar cliente.

### Resultado
El sistema informa si el cliente fue registrado correctamente.

En la versión inicial, el teléfono no cuenta con una validación de formato numérico.
