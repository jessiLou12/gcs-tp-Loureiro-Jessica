# Manual de Usuario

## Gestor de Clientes

El sistema permite registrar nuevos clientes mediante un formulario.

### Instrucciones
1. Abrir el archivo index.html en un navegador.
2. Ingresar el nombre del cliente.
3. Ingresar el correo electrónico.
4. Ingresar el teléfono.
5. Presionar Registrar cliente.

### Validación del teléfono
A partir de la versión 1.1, el teléfono debe contener exclusivamente números del 0 al 9.

Si se ingresan letras, espacios o símbolos, el sistema muestra el mensaje:
"El teléfono debe contener solamente números".

Si los datos son correctos, se informa que el cliente fue registrado correctamente.
